## O que é este repositório

Este NÃO é um projeto de software. É um repositório pessoal usado para versionar documentos de carreira de Rafael Zanini Francucci: currículo e materiais de preparação para entrevistas.

Não há código-fonte, build system, linter, testes ou dependências. Não tente aplicar fluxos de trabalho de desenvolvimento de software (build/lint/test) aqui — eles não existem neste repositório.

## Estrutura

Todos os documentos ficam em `docs/`:

- `Rafael_ZaniniFrancucci_Currículo.docx` / `.pdf` — currículo (versão em inglês/padrão)
- `Rafael_ZaniniFrancucci_Currículo_pt.pdf` — currículo em português
- `ReactInterview.pdf` — material de estudo/preparação para entrevistas de React
- `howToDoJobInterview.pdf` — material de preparação para entrevistas de emprego

## Ao trabalhar neste repositório

- Alterações são, em geral, adicionar, atualizar ou reorganizar esses arquivos de documento.
- Nomes de arquivo contêm acentos (ex.: "Currículo") — preserve a acentuação exata ao criar, mover ou referenciar arquivos.
- Arquivos binários (`.docx`, `.pdf`) não podem ser editados como texto; qualquer alteração de conteúdo precisa ser feita na ferramenta de origem e o arquivo resultante substituído no repositório.
